# 🎲 Jogo do Número Secreto

Jogo de adivinhação em que o jogador tenta descobrir um número sorteado entre 1 e 10, recebendo dicas de "maior" ou "menor" a cada tentativa. As dicas também são narradas por voz.

🔗 **Demo:** https://primeiro-projeto-ecru.vercel.app

## Funcionalidades
- Sorteio de número aleatório com `Math.random()`
- Dicas de maior/menor a cada tentativa
- Contador de tentativas
- Narração por voz com a biblioteca ResponsiveVoice
- Botão de reiniciar o jogo
- Layout responsivo em CSS

## Tecnologias
HTML · CSS · JavaScript

## Como rodar
Baixe o repositório e abra o `index.html` no navegador.
